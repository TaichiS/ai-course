Step 02

掃描後即連線。

遠端操控
—— Telegram

用自己的 Telegram Bot，把指令送進 Claude Code。

AI 不下班Ch.4 · Telegram17 / 42
Ch.4 · 動機

為什麼要多學一個
Telegram 模式？

QR Code 好用，
但有一個根本限制——

只能用 Claude 官方模型。

Telegram Channel 模式打破了這個限制——
你可以把底層模型換成任何相容的服務。
AI 不下班Ch.418 / 42
Ch.4 · 對照

兩種模式比較。

QR CodeTelegram Channel
連線方式掃碼，用官方 App自建 Telegram Bot
可用模型僅限 Claude可替換任意相容模型
上手難度極簡約 10 分鐘設定
彈性低高
AI 不下班Ch.419 / 42
Ch.4 · 流程概覽

五個步驟，
建立你自己的 Bot。

  1. 在 Telegram 向 @BotFather 建立 Bot，取得 Token
  2. 在 Claude Code 安裝 Telegram 插件
  3. 設定 Token
  4. 用 --channels 模式重新啟動
  5. 配對你的 Telegram 帳號

詳細步驟請參見講義。

AI 不下班Ch.420 / 42
Ch.4 · 安裝

安裝並配對
Telegram 插件。

在 Claude Code 內輸入
/plugin install telegram@claude-plugins-official
接著設定 Bot Token
/telegram:configure <token>

完成後，再用 Telegram Channel 模式
重新啟動 Claude Code。

AI 不下班Ch.421 / 42
Ch.4 · 啟動

啟動指令。

claude --channels plugin:telegram@claude-plugins-official \
       --permission-mode bypassPermissions

--permission-mode bypassPermissions
是必要的。

省略的話，Claude Code 每次操作都會停下來等你確認，
但你在手機上無法回應——對話就卡住了。

AI 不下班Ch.422 / 42
Ch.4 · 換模型

替換成其他模型。

用環境變數覆蓋 API 端點與金鑰。

export ANTHROPIC_AUTH_TOKEN="你的API金鑰" && \
export ANTHROPIC_BASE_URL="https://該服務的API網址" && \
CLAUDE_CODE_NO_FLICKER=1 claude \
  --channels plugin:telegram@claude-plugins-official \
  --permission-mode bypassPermissions

可替換的模型：Kimi、DeepSeek、GLM、MiniMax……

前提是該服務提供與 Anthropic API 相容的介面。

AI 不下班Ch.423 / 42
Ch.4 · 注意事項

三個容易踩到的坑。

01 · 離線
訊息會
直接消失
離線時送出的訊息不會排隊，會直接遺失。
02 · 記憶
重啟即
清空對話
每次重新啟動，它不記得上次說了什麼。
03 · 圖片
建議用「以
檔案傳送」
避免 Telegram 預設的壓縮失真。

PDF 轉 Markdown
不要硬交給 AI

把 PDF 轉成可整理、可搜尋、可再加工的 Markdown。

AI 不下班Ch.6 · PDF31 / 42
Ch.6 · 失敗案例

把 PDF 直接丟給 Claude Code，
會發生什麼？

  • 極高機率出現亂碼
  • 圖片資訊容易消失
  • 表格結構容易散掉
  • 版面順序可能被誤判
根本原因
PDF 不是純文字檔。
不能期待模型直接「讀懂格式」。
AI 不下班Ch.632 / 42
Ch.6 · 我的做法

改用專門工具。

先用 marker-pdf
做 PDF 解析與轉換。

pip install marker-pdf

再把轉出來的 Markdown
交給 Claude Code 處理。

先讓工具把資料救出來，
再讓 AI 把內容整理好。
AI 不下班Ch.633 / 42
Ch.6 · 二次檢查

轉檔只是第一步，
接著請 AI 檢查。

  • 有沒有亂碼
  • 標題層級是否正確
  • 表格是否需要重建
  • 圖片說明是否需要補上
  • 段落順序是否合理
AI 不下班Ch.634 / 42
Ch.6 · 分工原則

這樣分工，
比較穩。

專門工具
負責
解析 PDF
AI
負責內容整理
  • 修復亂碼
  • 重整段落
  • 補齊說明
  • 改成適合閱讀與再利用的 Markdown
