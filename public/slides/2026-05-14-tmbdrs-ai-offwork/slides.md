## Chapter 1 · 用 Claude Design 製作投影片

> 目標：示範從零開始，用 AI 生成可直接使用的投影片

---

## 什麼是 Claude Design？

Claude 的視覺創作模式。

不是改文字、不是套模板——
**描述你要的內容，它幫你設計整份簡報。**

---

## 示範：這份投影片怎麼做的

**Step 1｜描述課程內容**

```
幫我製作一份投影片，
主題是「AI 不下班：遠端自動化與創作流程」，
對象是醫師，
包含 QR Code 遠端操控、Telegram 遠端操控、
投影片製作、Netlify 部署、瀏覽器操作五個章節。
```

---

## 示範：這份投影片怎麼做的

**Step 2｜調整細節**

- 修改標題、調整文字
- 換配色、改版型
- 刪掉不需要的頁面

**Step 3｜輸出**

- 直接下載 HTML
- 如果有其他檔案，務必全部下載，放在一起。

---

## 為什麼投影片適合用 AI 做？

- 結構是固定的（標題、內文、圖表）
- 不需要像論文一樣字字斟酌
- 改稿成本低，試了不滿意就重來

**最適合讓 AI 出第一稿，你再調整方向。**

## Chapter 2 · 投影片部署到 Netlify

> 目標：讓投影片有一個公開網址，可以分享、可以在任何裝置看

---

## 為什麼要部署？

做完的投影片放在自己電腦裡：
- 要帶電腦才能播
- 沒辦法傳連結給別人

部署到 Netlify 之後：
- 有固定網址，手機也能開
- 上課直接用網頁簡報，不需要準備裝置

---

## Netlify 是什麼？

靜態網站託管服務。

- 免費方案已足夠個人使用
- 支援拖曳上傳，幾秒完成部署
- 自動產生 `xxxxx.netlify.app` 網址

---

## 部署方式

**方式一：拖曳上傳（最簡單）**

把資料夾直接拖進 Netlify 網頁，完成。

**方式二：讓 Claude Code 幫你部署**

```
使用 netlify cli 幫我把這個資料夾部署到 Netlify，
並把網址告訴我。
```

## Chapter 3 · 遠端操控：QR Code

> 目標：讓學員能用手機直接接管電腦上的 Claude Code

---

## 你的電腦可以被你的手機控制

Claude Code 內建 **Remote Control** 功能：

- 在電腦上啟動 Claude Code
- 用手機掃描 QR Code
- 從此，手機就是你電腦的遠端遙控器

---

## 怎麼啟動？

**Step 1｜在 Claude Code 輸入**

```
/remote-control
```

**Step 2｜畫面會出現 QR Code**

用 Claude 官方手機 App 掃描。
如果沒有出現，就叫它顯示。

**Step 3｜掃描後即連線**

手機畫面直接顯示你電腦上的 Claude Code 對話。

---

## 可以做什麼？

- 離開電腦後，繼續下指令讓 Claude Code 工作
- 查看長時間任務的執行進度
- 臨時想到什麼，馬上叫它處理

---

## QR Code 模式的限制

| 項目 | 說明 |
|------|------|
| **模型** | 只能用 Anthropic 官方模型（Claude） |
| **操作感** | 像遙控器，接管現有 session |
| **上手難度** | 最簡單，掃碼即用 |

## Chapter 4 · 遠端操控：Telegram

> 目標：用自己的 Telegram Bot 把指令送進 Claude Code

---

## 為什麼要多學一個 Telegram 模式？

QR Code 好用，但有一個根本限制：

**只能用 Claude 官方模型。**

Telegram Channel 模式打破了這個限制——
你可以把底層模型換成任何相容的服務。

---

## 兩種模式比較

| | QR Code | Telegram Channel |
|--|---------|-----------------|
| **連線方式** | 掃碼，用官方 App | 自建 Telegram Bot |
| **可用模型** | 僅限 Claude | 可替換任意相容模型 |
| **上手難度** | 極簡 | 約 10 分鐘設定 |
| **彈性** | 低 | 高 |

---

## 設定流程概覽

1. 在 Telegram 向 **@BotFather** 建立 Bot，取得 Token
2. 在 Claude Code 安裝 Telegram 插件
3. 設定 Token
4. 用 `--channels` 模式重新啟動
5. 配對你的 Telegram 帳號

詳細步驟請參見講義。

---

## 啟動指令

```bash
claude --channels plugin:telegram@claude-plugins-official \
       --permission-mode bypassPermissions
```

**`--permission-mode bypassPermissions` 是必要的。**

省略的話，Claude Code 每次操作都會停下來等你確認，
但你在手機上無法回應——對話就卡住了。

---

## 替換成其他模型

用環境變數覆蓋 API 端點與金鑰：

```bash
export ANTHROPIC_AUTH_TOKEN="你的API金鑰" && \
export ANTHROPIC_BASE_URL="https://該服務的API網址" && \
CLAUDE_CODE_NO_FLICKER=1 claude \
  --channels plugin:telegram@claude-plugins-official \
  --permission-mode bypassPermissions
```

可替換的模型：Kimi、DeepSeek、GLM、MiniMax……
前提是該服務提供與 Anthropic API 相容的介面。

---

## 注意事項

- 離線時送出的訊息會**直接消失**，沒有排隊
- 每次重新啟動，**對話記憶清空**，它不記得上次說了什麼
- 傳圖片建議用「以檔案傳送」，避免 Telegram 壓縮失真

## Chapter 5 · Skills：把工具磨成工作流

> 來源：高見龍（一個台灣軟體工程師）的臉書留言

---

## Skills 的使用流程

1. 聽說某個大神的 Skills 很猛
2. 下載下來，先丟給 AI 解說內容
3. 順便請 AI 掃一下有沒有藏奇怪的東西
4. 安裝起來試用看看
5. 不好用就移掉，好用就留下來

---

## 真正的重點在後面

用久了一定會開始感覺哪裡不太順：

- 這個流程不對
- 這段提示詞太囉嗦
- 這個步驟其實可以省略
- 這個輸出格式不符合我的工作方式

這時候，不是換下一個 Skills。

---

## 請 AI 幫你改 Skills

把你的不順手講出來：

```
這個流程不對。
這段提示詞太囉嗦。
這個輸出不是我要的格式。
請幫我調整這個 Skill。
```

改著改著，Skills 就會變成你自己的形狀。

---

## 不要只下載大神配置

並不是下載到大神的 Skills，就會變大神。

如果從來沒有走過「使用、抱怨、修改」的流程，
很容易變成：

- 一直追新工具
- 一直換新 Skills
- 一直下載大神配置
- 什麼都沒有真正內化

---

## Skills 是需要磨的

每個人的使用情境、工作習慣、輸出標準都不同。

所以好的 Skills 不只是「別人寫好的工具」，
而是你把它磨成自己的工作流。

> **工具不是拿來收藏的，是拿來被你改到順手的。**

## Chapter 6 · PDF 轉 Markdown：不要硬交給 AI

> 目標：把 PDF 內容轉成可整理、可搜尋、可再加工的 Markdown

---

## 直接請 Claude Code 轉 PDF 的問題

如果直接把 PDF 丟給 Claude Code，請它轉成 Markdown：

- 極高機率出現亂碼
- 圖片資訊容易消失
- 表格結構容易散掉
- 版面順序可能被誤判

PDF 不是純文字檔，不能期待模型直接「讀懂格式」。

---

## 我的實作：改用專門工具

先用 `marker-pdf` 做 PDF 解析與轉換：

```bash
pip install marker-pdf
```

再把轉出來的 Markdown 交給 Claude Code 處理。

---

## 轉完之後再請 AI 檢查

轉檔只是第一步。

接著請 Claude Code 幫你檢查：

- 有沒有亂碼
- 標題層級是否正確
- 表格是否需要重建
- 圖片說明是否需要補上
- 段落順序是否合理

---

## 這樣分工比較穩

專門工具負責解析 PDF。

AI 負責：

- 修復亂碼
- 重整段落
- 補齊說明
- 改成適合閱讀與再利用的 Markdown

> **先讓工具把資料救出來，再讓 AI 把內容整理好。**

## Chapter 7 · 瀏覽器操作與注意事項

> 目標：讓學員知道 Claude Code 能控制瀏覽器，以及安全邊界在哪

---

## Claude Code 能控制你的瀏覽器

透過 **Playwright** 或瀏覽器 MCP，Claude Code 可以：

- 自動開啟網頁
- 點按鈕、填表單
- 截圖、擷取資料
- 模擬完整的人類操作流程

---

## 醫師可以用在哪？

- 自動登入網站，擷取報表
- 定時抓取特定網頁的更新內容
- 填寫重複性表單

---

## 重要注意事項

**速度**
瀏覽器操作比一般文字處理慢很多，
複雜任務可能需要幾分鐘。

**穩定性**
網頁改版、登入驗證碼、動態載入——
都可能讓自動化中途失敗。

**倫理與合規**
不要用來繞過系統的存取控制。
自動化操作是否符合該平台的使用條款，需要自行確認。

---

## 一個原則

> **能手動做一次、說清楚步驟的事，才適合讓 AI 自動化。**

如果你自己都不確定怎麼操作，
AI 也很難做對。
