# 📝 Marp：Markdown 的簡報魔法

- **專注內容**：用 Markdown 寫簡報，告別繁瑣排版
- **AI 友善**：AI 最擅長生成結構化文字 -> 秒產簡報
- **工程美學**：
  - 版本控制 (Git)
  - 像寫程式一樣「刻」簡報

# 🚧 真相：AI 代理人不是全知的神

<span class="warning">三大邊界限制：</span>

1. **商業邊界**：AI 穿不透付費期刊的 Paywall。
2. **格式邊界**：文字提取工具對複雜公式與圖表是「盲人摸象」。
3. **可及性邊界**：給它 ArXiv 它是科學家，給它封閉平台它只是讀報生。
