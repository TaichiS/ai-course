OpenClaw Windows 安裝指南

透過 WSL 在 Windows 上安裝 OpenClaw，打造你的專屬 AI 助理

Windows 10/11
WSL + Ubuntu
約 10-15 分鐘

前置需求

  • • Windows 10 版本 2004 及以上（建議 Windows 11）
  • • 需要系統管理員權限
  • • 穩定的網路連線
1

檢查 WSL 狀態

開啟 PowerShell（系統管理員），執行以下指令檢查 WSL 是否已安裝：

wsl --version

預期輸出（表示 WSL 已安裝）：

WSL 版本：2.x.x.x
核心版本：5.x.x
WSLg 版本：1.x.x
2

安裝 WSL

如果 WSL 尚未安裝，執行以下指令（需要管理員權限）：

wsl --install

安裝過程會：

  • • 啟用 WSL 功能
  • • 啟用虛擬機平台
  • • 下載並安裝 Ubuntu

安裝完成後請重新啟動電腦

3

設定 Ubuntu 使用者帳號

重新開機後，Ubuntu 會自動啟動，請設定使用者帳號和密碼：

Enter new UNIX username: your_username
New password: ********
Retype new password: ********
Password updated successfully

請記住這組帳號密碼！ 後續步驟會需要用到。

4

設定 sudo 免密碼（重要）

為了讓 OpenClaw 能順利運作，需要設定 sudo 免密碼：

sudo visudo

編輯器操作步驟：

  1. 使用方向鍵移動到檔案最下方
  2. 新增一行：your_username ALL=(ALL) NOPASSWD: ALL
    （將 your_username 換成你的使用者名稱）
  3. 按 Ctrl + O 儲存
  4. 按 Enter 確認檔名
  5. 按 Ctrl + X 離開
5

安裝 OpenClaw

執行官方安裝指令，會自動安裝 Node.js 和 Python 環境：

curl -fsSL https://openclaw.ai/install.sh | bash

安裝過程會自動：

  • • 安裝 Node.js（如果尚未安裝）
  • • 安裝 Python（如果尚未安裝）
  • • 安裝 OpenClaw CLI
  • • 設定環境變數
6

驗證安裝

安裝完成後，重新開啟 WSL 終端機，執行以下指令驗證：

openclaw --version

預期輸出：

openclaw version x.x.x
7

啟動 OpenClaw

現在可以啟動 OpenClaw 了：

openclaw gateway start

背景模式啟動

openclaw

互動模式

常見問題

Q1: WSL 安裝失敗，顯示「虛擬化未啟用」

解決方案：

  1. 進入 BIOS 啟用 Intel VT-x 或 AMD-V
  2. 或在 PowerShell 執行：
bcdedit /set hypervisorlaunchtype auto

然後重新啟動電腦

Q2: Ubuntu 無法啟動

wsl --shutdown
wsl --unregister Ubuntu
wsl --install -d Ubuntu

Q3: OpenClaw 指令找不到

source ~/.bashrc
# 或重新開啟 WSL 終端機

Q4: visudo 編輯器不會用

替代方案：

sudo usermod -aG sudo $USER
sudo nano /etc/sudoers
# 加入：your_username ALL=(ALL) NOPASSWD: ALL

🎉 安裝完成！
