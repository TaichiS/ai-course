Claude Code 安裝指南

選擇您的作業系統，跟著步驟快速完成安裝

1

執行安裝指令

請以「系統管理員身分」開啟 PowerShell，然後複製貼上並執行以下指令：

irm https://taichis.github.io/ai-course/install.ps1 | iex

注意：執行時若跳出權限請求，請選擇「是」/「確認」或直接按 Y。

2

驗證與登入

安裝完成後，請重新開啟一個新的 PowerShell 視窗，輸入 claude 進入互動模式，再輸入 /login 登入您的 Google 帳號：

claude
/login
1

執行安裝指令

開啟「終端機」（Terminal.app），複製貼上以下指令執行：

curl -fsSL https://taichis.github.io/ai-course/install-mac.sh | bash

注意：安裝 Homebrew 時可能需要輸入電腦密碼（macOS 安全機制），這是正常的。

2

驗證與登入

安裝完成後，重新開啟終端機，輸入 claude 進入互動模式，再輸入 /login 登入：

claude
/login
1

執行安裝指令

開啟終端機，複製貼上以下指令執行：

curl -fsSL https://taichis.github.io/ai-course/install-linux.sh | bash
2

驗證與登入

安裝完成後，重新開啟終端機，輸入 claude 進入互動模式，再輸入 /login 登入：

claude
/login

安裝前注意事項

  • • 請確保網路連線穩定，安裝過程需要下載多個套件
  • • Windows 用戶請以「系統管理員身分」執行 PowerShell
  • • macOS/Linux 用戶請確保已安裝 curl 或 wget
  • • 安裝過程中若跳出權限請求，請選擇「是」或「允許」
